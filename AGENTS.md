# Project instructions

- Keep the quiz in the standalone `index.html` file. Use vanilla HTML, CSS, and JavaScript; do not add frameworks, libraries, build steps, or runtime network requests.
- Preserve direct `file://` use, offline behavior, responsive layouts, and the existing light/dark and reduced-motion support.
- Keep the interface child-friendly and accessible: semantic controls, visible keyboard focus, screen-reader labels, clear feedback, and touch-sized buttons.
- When changing quiz behavior, test the complete flow in the integrated browser, including scoring, progress, feedback, results, replay, and a narrow viewport.
- Keep edits focused, readable, and consistent with the existing design. Do not introduce unrelated files or features.
